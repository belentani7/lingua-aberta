# Ecosistema educativo Belentani / NOIACORE

Este repositorio es una hermana del ecosistema educativo común. Conserva su
arquitectura, sus datos y su propósito propios; esta relación no convierte los
repositorios en un monolito ni autoriza mover o borrar contenido.

## Papel de este proyecto

Campus lingüístico offline-first con datos abiertos y tutor

## Regla de interoperabilidad

- Este proyecto mantiene su stack y su ciclo de despliegue.
- Las hermanas comparten principios, enlaces y vocabulario, no dependencias
  internas obligatorias.
- El índice de entrada del ecosistema es
  [open-school/INDICE-EDUCATIVO.md](https://github.com/belentani7/open-school/blob/main/INDICE-EDUCATIVO.md).
- Las afirmaciones de cobertura, cursos, idiomas, recursos o certificaciones deben
  estar respaldadas por contenido verificable del propio repositorio.
- No se deben subir secretos, PII ni material privado de otras hermanas.
